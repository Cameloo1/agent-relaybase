# TUI Setup And Operator Agent Gap Map

This document maps the RA global addendum gaps to owner prompts or explicit deferrals. It is updated through RA010 for Agent Gateway, OpenRouter compatibility, daemon runtime, daemon-owned tool registry, durable session/audit storage, budget/redaction behavior, and Go TUI Agent Gateway integration.
